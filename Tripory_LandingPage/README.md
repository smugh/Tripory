# Tripory Landing Page

A lightweight, responsive public landing page for Tripory. English is the default language; visitors can switch to Indonesian with the EN / ID control.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Publish

This site is plain HTML, CSS, and JavaScript and can be hosted with GitHub Pages from the `main` branch root.

The Android download button links to the latest published Tripory release asset. Update its version, APK URL, file size, release notes link, and structured metadata when publishing a new app release.

## Content and assets

The app overview describes the public Tripory v1.0.2 release. Local-first behavior and device storage are described based on the mobile app's current architecture.
